# PHỐ LINH — Skill effect frames WebP

Bộ này gồm 2 skill effect đã được cắt thành frame WebP riêng:

- **Sương Mù Xâm Thực** (`skill_suong_mu_xam_thuc`): Phát tán sương lạnh, gây sát thương Thủy nhẹ và giảm tốc độ hành động của mục tiêu.
- **Long Miêu Liên Kích** (`skill_long_mieu_lien_kich`): Tung nhiều đòn tấn công liên tiếp bằng móng vuốt, gây sát thương dồn lên một mục tiêu.

## Rule xử lý

- Frame trước không dính frame sau.
- Tính chiều rộng / chiều cao chuẩn theo frame to nhất của từng skill.
- Toàn bộ frame của skill được chuẩn hóa theo size đó.
- Xuất WebP để nhẹ dung lượng.
