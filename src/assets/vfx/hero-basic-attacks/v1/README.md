# PHỐ LINH — Basic Attack Spritesheet Frames (5 Hệ)

Package này chứa bộ frame WebP cho đòn đánh thường của 5 hệ: Kim, Mộc, Thủy, Hỏa, Thổ.

## Danh sách hệ

- **Đòn Đánh Thường — Hệ Kim** — thư mục `basic_attack_kim_kiem_v2`
- **Đòn Đánh Thường — Hệ Mộc** — thư mục `basic_attack_moc_gay_v2`
- **Đòn Đánh Thường — Hệ Thủy** — thư mục `basic_attack_thuy_thuong_v2`
- **Đòn Đánh Thường — Hệ Hỏa** — thư mục `basic_attack_hoa_cung_v2`
- **Đòn Đánh Thường — Hệ Thổ** — thư mục `basic_attack_tho_dao_v2`

## Quy tắc chung

- Ảnh nền trong suốt.
- WebP lossless để không bị nhòe.
- Mỗi hệ được cắt 6 frame, dùng frame lớn nhất làm chuẩn kích thước.
- Không để frame trước dính frame sau.
