# Băng Phong Thiên Lý

- **Skill ID:** `skill_bang_phong_thien_ly`
- **Hệ:** thuy
- **Nền:** Trong suốt hoàn toàn (bản sửa V3)
- **Frame chuẩn:** 512 x 512px

## Ghi chú

- Đã loại bỏ nền đen còn sót mạnh tay hơn bản trước.
- Frame độc lập, không chồng chéo, không dính frame khác.

## Quy ước runtime

- Đây là FX-only, không chứa nhân vật hoặc quái.
- Canvas WebP RGBA trong suốt 512 x 512, pivot ở tâm.
- Chạy một lần ở 8 FPS và bay từ nhân vật tới mục tiêu.
