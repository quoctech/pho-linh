# PHỐ LINH — Skill Icons WebP

Bộ này được cắt từ sheet icon kỹ năng tổng hợp.

## Đã xử lý

- Tách từng icon riêng, không chồng chéo nhau.
- Cắt theo biên thực tế của từng icon.
- Xuất định dạng **WebP**.
- Có `manifest.json` để tra tên file và toạ độ gốc.
