# PHỐ LINH — Passive Icons (Ngũ Hành)

Gói này chứa 5 icon nội tại của 5 hệ phái, đã tách riêng thành từng file WebP.

## Danh sách icon

- **Kim** — **Kiếm Tâm Bất Diệt**
  - File: `icons_webp/kim_kiem_tam_bat_diet.webp`
  - Kích thước chuẩn: 296 x 352 px
  - Mô tả: Từ đòn thứ hai liên tiếp, có 40% chí mạng và tăng 40% sát thương.

- **Mộc** — **Sinh Cơ Bất Tận**
  - File: `icons_webp/moc_sinh_co_bat_tan.webp`
  - Kích thước chuẩn: 296 x 352 px
  - Mô tả: Tăng 40% hồi phục khi quái đang Dính độc.

- **Thủy** — **Hàn Tức Ngưng Kết**
  - File: `icons_webp/thuy_han_tuc_ngung_ket.webp`
  - Kích thước chuẩn: 296 x 352 px
  - Mô tả: Giảm 25% sát thương từ hit thứ ba liên tiếp.

- **Hỏa** — **Liệt Diễm Chi Tâm**
  - File: `icons_webp/hoa_liet_diem_chi_tam.webp`
  - Kích thước chuẩn: 296 x 352 px
  - Mô tả: Thiêu đốt mục tiêu và cộng 20 sát thương khi mục tiêu đang cháy.

- **Thổ** — **Bất Động Như Sơn**
  - File: `icons_webp/tho_bat_dong_nhu_son.webp`
  - Kích thước chuẩn: 296 x 352 px
  - Mô tả: Giảm 10% sát thương khi đang có Khiên.

## Thành phần package

- `icons_webp/`: chứa 5 icon WebP
- `manifest.json`: thông tin file, mô tả, crop box
- `README.md`: tài liệu mô tả package
